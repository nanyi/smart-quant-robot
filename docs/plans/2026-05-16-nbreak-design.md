# 精准N破战法 - 设计文档

## 1. 策略概述

**精准N破战法**是基于N字形态的突破交易系统，仅依赖价格行为与成交量验证，遵循「突破即进、破位即走」原则。

**核心特征**：
- 单次交易决策（不补仓、不扛单、不幻想）
- ATR动态风控
- 20日均线过滤趋势方向

## 2. 策略参数配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `ma_period` | 20 | 均线周期 |
| `strong_rise_period` | 10 | 强势拉升段K线数量 |
| `strong_rise_min_count` | 2 | 强势拉升段最小阳线数 |
| `strong_rise_body_ratio` | 1.2 | 拉升段平均K线实体/ATR比率 |
| `volume_amplify_ratio` | 1.2 | 成交量放大倍数（较前期均量） |
| `pullback_volume_ratio` | 0.7 | 缩量回踩比例 |
| `breakout_volume_ratio` | 1.2 | 放量突破比例 |
| `breakout_threshold` | 0.01 | 突破确认阈值（1%） |
| `atr_period` | 20 | ATR计算周期 |
| `atr_stop_loss_ratio` | 2.0 | ATR止损倍数 |

## 3. 交易规则

### 3.1 N字形态识别流程

```
┌─────────────────────────────────────────────────────────┐
│  阶段1: 强势拉升段                                      │
│  - 过去N根K线中至少M根阳线                              │
│  - 平均K线实体 > ATR * strong_rise_body_ratio          │
│  - 成交量较前期放大                                     │
│  - 价格在20日均线上方                                   │
└─────────────────────────────────────────────────────────┘
                         ↓ (价格回落)
┌─────────────────────────────────────────────────────────┐
│  阶段2: 缩量回踩段                                      │
│  - 成交量萎缩（低于前期均量）                            │
│  - 回调低点不跌破20日均线                                │
│  - 记录回踩段前高（用于后续突破比较）                    │
└─────────────────────────────────────────────────────────┘
                         ↓ (价格反弹突破前高)
┌─────────────────────────────────────────────────────────┐
│  阶段3: 放量突破 & 入场                                  │
│  - 价格 > 回踩段前高 * (1 + threshold)                  │
│  - 成交量放大                                           │
│  → 触发BUY信号                                          │
└─────────────────────────────────────────────────────────┘
```

### 3.2 入场条件（必须全部满足）

1. **趋势过滤**：价格在20日均线上方
2. **强势拉升段**：
   - 过去N根K线中至少M根阳线
   - 平均K线实体 > ATR * strong_rise_body_ratio
   - 成交量较前期放大
3. **缩量回踩段**：
   - 价格回落（从拉升段高点下跌）
   - 回调低点不跌破20日均线
4. **放量突破段**：
   - 价格突破回踩段前高（收盘价 > 前高 * 1.01）
   - 成交量放大

### 3.3 出场条件

| 类型 | 触发条件 |
|------|----------|
| **止损** | 价格 < 入场价 - ATR止损倍数*ATR |
| **止盈** | 价格 > 入场价 * 1.10 |
| **破位** | 价格 < 20日均线 且 成交量放大 |

## 5. 状态管理

- `_in_rise_phase`: 是否处于拉升阶段
- `_in_pullback_phase`: 是否处于回踩阶段
- `_pullback_low`: 回踩段最低价
- `_pullback_high`: 回踩段前高（拉升段最高价）
- `position_opened`: 是否持仓

## 6. 配置集成

在 `config.yaml` 中添加：
```yaml
strategy:
  nbreak:
    ma_period: 20
    strong_rise_period: 10
    strong_rise_min_count: 2
    strong_rise_body_ratio: 1.2
    volume_amplify_ratio: 1.2
    pullback_volume_ratio: 0.7
    breakout_volume_ratio: 1.2
    breakout_threshold: 0.01
    atr_period: 20
    atr_stop_loss_ratio: 2.0
```
